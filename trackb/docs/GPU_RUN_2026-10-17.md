## Fixes made during GPU validation (code hash `f616881b…` for the formal run)

| Problem (evidence) | Fix |
|---|---|
| R3 "sampling" was greedy: Qwen2-VL `generation_config` ships `top_k=1`, so 4 candidates per tile were identical (`smoke_4080_v1/r3_identical_candidates_example.json`) | `top_k=0` when sampling (pure nucleus, T=0.8, p=0.95). After the fix 4/4 unique samples; formal R3 accepted 723 and 732 of 4,000 |
| Scoring did 9 separate forwards + 18 processor calls per tile: 0.54–0.78 s/tile | Nine candidates in one right-padded batch, same prompt/tokens/sum-log-lik rule: 0.24–0.29 s/tile, predictions identical on 12/12 profiled tiles, max prob diff 0.047 (bf16 batching) |
| Unmerged LoRA decoding at 19.6 tok/s | Inference-only students `merge_and_unload()`: 1.9× faster, identical text |
| Rationales generated one tile at a time (1.56 s/tile) | Left-padded batches of 8 (`model.generate_batch`): 0.32 s/tile, 7/8 texts identical, the other differed in a late token |
| Smoke R2 collapsed class scoring to one class (BA 0.11) | Optional `r2.class_replay_fraction` (0.5 in formal) mixes R1 class targets into R2 training; `targets/r2.jsonl` stays grounded-only, so R3/feedback replay is unchanged |
| Grounding threshold grid topped out at 0.04 while precision kept rising | Formal grid extended to 0.15 |

The prediction contract string changed (`…; nine candidates batched right-padded`) so older partial
prediction files can never be resumed into new outputs. 15/15 CPU tests still pass after the changes.

### Findings worth reporting

1. Post-training makes the 2B VLM see the tissue: 0.23 → 0.83 balanced accuracy, but it is still well
   below the 97.7 % CONCH probe. STR/MUS (~32 % pair error) is the dominant remaining confusion.
2. R2 cut NORM/TUM confusion in half (0.155 → 0.074) and produced 94 % well-formed differential rationales.
   Overall balanced accuracy stayed flat because BACK recall dropped.
3. The automatic region teacher is weak. On train_dev the descriptor class-match precision is only
   0.12–0.16 at every threshold (target 0.8 was never reached; threshold 0.15 chosen by fallback). In a
   54-tile probe CONCH got 61 % with whole-tile class names, 37–48 % with whole-tile descriptors, and 26 %
   with descriptors on 112 px crops. Grounding pass rate (22 %) is bounded by this teacher.
4. R3 self-training ran both rounds on real accepted data (18 % acceptance) but did not improve dev over R2.
